## Course Philosophy

LLMs are changing the way we develop software

It is too early to create a structured course on this topic (e.g., 12 frontal lectures)

- Many organizations just started experimenting with AI for Coding
- AI tools are also evolving really fast ("prompt engineering is dead")

But it is not too early to start experimenting with AI tools for coding to understand how they help our productivity, and what their limits are.

This course is a combination of frontal lectures, tutorials, guest lectures and project work to experiment with AI-supported coding.

## Course Objectives

The students know the basic application of AI models to various aspects of software development including coding, testing, code reviews, bug fixing.

The students know the social and organizational implications of introducing AI tools in the software development process.

The students are familiar with the main challenges connected to the use if AI in software development, including correctness, privacy, intellectual property.

Students can successfully evaluate the application of AI tools to software development processes estimating their impact on productivity.

Students can directly transfer the results of this course to their own ongoing software projects.

## Course Content

The course covers the use of AI-based tools in the software development process, considering common use cases and issues like reliability and security.

AI-based tools are significantly changing the practice of coding, potentially increasing the productivity of developers but also posing a number of challenges related to the quality of the generated result and the integration into the broader context of the software development process. Keeping up to date with these recent advances is crucial because of their impact on digital organizations.

This course complements the courses on programming and software engineering by focusing on the support that AI tools can provide for developers. The target audience consists of students that are proficient in programming and who are familiar with the fundamental aspects of software development such as specification, coding, testing, code reviewing and maintenance.

## Final report

Individual work, individual grade 6 pages, A4 format, 12 points, Times font

- 1 - Describe the project structure and results (especially if different compared to the project description)
- 2 - For the structure: focus on points A and B

## Some suggestions for the final report:

- Which AI tools did you use?
- Which interaction modality was effective for each task? (e.g., prompting, code completion, …)
- For which tasks was AI effective
- Where did AI fail?
- What was the best workflow?
- For which software-related activities was AI effective except for coding? (testing, fixing, requirements, …)
