## Generative AI: The What

## Definition:

- A generative AI model is a type of AI that can create new content, such as text, images, audio, or video, based on the data it has been trained on.

## User Interaction:

- Users provide input or prompts (like a question or a request), and the model generates an appropriate response or output.

## Examples:

- Generating written articles, creating artwork, composing music, or even engaging in human-like conversations.

Purpose: Assessing and improving outputs.

Description: The AI generates content, which is then evaluated. Based on this evaluation, the model is retuned to enhance the quality and accuracy of its outputs continuously.

University of St.Gallen Continuous Improvement: Regularly assess and fine-tune the model for accuracy and relevance (e.g., weekly).

Foundation Model Updates: Less frequent, updated every 12-18 months.

## Retrieval Augmented Generation (RAG):

- Purpose: Enhance performance by incorporating external, up-to-date sources.
- Process: Extends the foundation model to use relevant data beyond its original training set.
- Benefits: Provides transparency and ensures access to current information.

## Hallucinations: The What

## What are hallucinations?

- internal contradiction
- "The lake is blue … the lake is green."
- contradiction with prompt
- I ask to write a positive review of a course, and it returns: "The content was terrible, and the teacher was rude."
- factual contradictions
- "Bacchelli was the first president of the HSG"

## Why Do Hallucinations Happen?

- Data quality

- Output generation algorithm
- predict the next word
- Input context

## Hallucinations: The How To Reduce

## How to reduce hallucinations

- Provide clear and specific prompts
- "Explain inflation." vs. "Can you explain the concept of inflation, including how it is measured, the factors that contribute to rising inflation rates, and its impact on both consumers and the overall economy? Please include examples from recent events."
- Multi-shot prompting
- multiple examples helps it recognize patterns and context more effectively, e.g., for formatting output and writing style
- IVO: Immediately Verifiable Output
- Retrieval Augmented Generation (RAG)
- Run the code!

## Coding limitations

Limitation mostly relevant for more complex coding tasks

Potential for Errors: AI-generated code can contain bugs

Lack of Context Understanding: AI might miss the broader context behind the code, due to input size.

Security Risks: AI can introduce security flaws or suggest insecure coding practices.

Proprietary Data Risks: Sharing proprietary code or data with AI tools can pose intellectual property risks.

## Studies on security risks:

- One study found that Copilot generates insecure code about 40% of the time (https://arxiv.org/pdf/2304.09655)
