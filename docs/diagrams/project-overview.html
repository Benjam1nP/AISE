Overview · Coding with AI · WS 2026

An AI-assisted software engineering environment

The developer works in one workspace. An orchestrator walks the project through seven phases and stops for approval after each one. Agents do the work through MCP tools, and every artefact lives as a file in the project folder.

The differentiator

Drift repair and traceability

The design is a typed JSON model; Mermaid diagrams are generated from it. ts-morph extracts the same model from the code, and the difference is the drift. The developer picks the repair direction: update the design or update the code.

Shared IDs (REQ-012, DSN-004, @trace DSN-004 REQ-012 in code) link every requirement to its diagram elements, code and tests.

Seven phases

One gate after each

  • P1 Requirements: asks before it guesses · Sonnet
  • P2, P3 Design and refinement: UML, self review · Opus
  • P4 Code: mirrors the class diagram · Sonnet
  • P5 Tests: one per use case, run, explain, fix · Sonnet
  • P6 Deploy: Dockerfile and compose · Sonnet
  • P7 Maintenance: change requests, drift · Opus
